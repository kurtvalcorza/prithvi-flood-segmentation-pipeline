No licence or remote-code gate is open for DIMER hosting (Apache-2.0 weights; the model class comes from `terratorch` on PyPI). One review item is open on the asset side: the upstream file is a Lightning pickle, which this repository audits statically and converts once — through torch's weights-only loader — into a digest-pinned safetensors file that is the only artifact the runtime path loads; whether that meets the DIMER deserialization-trust bar, or whether DIMER should host only the maintainer-converted file, is the maintainer's call. See `MODEL_CARD.md` (*DIMER deployment notes*) and `docs/WEIGHTS.md`.
